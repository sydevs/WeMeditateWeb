# The playground's crawler policy, and the one place it is written down (#174).
#
# A component playground is no more a search surface than the app is, and this one answers on
# its own domain, so there is a URL worth keeping out of an index. Two signals carry that:
# this file (do not fetch) and `X-Robots-Tag` in `_headers` (do not index, on every URL).
# Ladle generates its own `index.html`, so a `<meta robots>` is not available as a third.
#
# THE INTERACTION THAT MATTERS. `Disallow` means "do not fetch", not "do not index" — so a
# compliant crawler that never fetches a page also never sees the `noindex` served on it. The
# two do not stack; the weaker signal hides the stronger. Residual risk, accepted: a URL
# linked from an external page can still be listed URL-only, with no title or snippet.
#
# RUNBOOK. If design.wemeditate.com is ever found in an index, relax this file rather than
# tightening it — swap `Disallow: /` for `Allow: /` so the crawler can fetch the page, read
# the `noindex` and drop the entry, then restore this once it is gone.
User-agent: *
Disallow: /

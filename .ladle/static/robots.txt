# Cloudflare Pages serves this from the Ladle build output. It ships from `.ladle/static/`
# rather than `public/`, because `public/` is copied into the Vike app's build as well, where
# this file would answer on wemeditate.com and tell every crawler to drop the site. The app
# builds its own refusal per host, in `server/sitemap.ts`.
#
# A component playground is no more a search surface than the app is, and this one answers on
# a custom domain, so there is a URL worth keeping out of an index (#174).
#
# Two signals carry that, and they are not interchangeable:
#   - this file     — do not fetch.
#   - X-Robots-Tag  — do not index, on every URL (`_headers` beside this file).
#
# A `<meta robots>` is not a third: Ladle generates its own `index.html`, so a tag added
# anywhere in this repo never reaches the playground. The header has to carry it.
#
# THE INTERACTION THAT MATTERS. `Disallow` means "do not fetch", not "do not index" — so a
# compliant crawler that never fetches a page also never sees the `noindex` served on it. The
# two do not stack; the weaker signal hides the stronger. Residual risk, accepted: a URL
# linked from an external page can still be listed URL-only, with no title or snippet.
#
# RUNBOOK. If design.wemeditate.com is ever found in an index, relax this file rather than
# tightening it — swap `Disallow: /` for `Allow: /` so the crawler can fetch the page, read
# the `noindex` and drop the entry, then restore this once it is gone.
User-agent: *
Disallow: /
